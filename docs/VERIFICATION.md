### 지적사항

1. **[검증도구 버그]** 카피 비교 시 `<br>` 을 공백 없이 제거해
   `즐기고,<br>선생님은` → `즐기고,선생님은` 으로 붙어 3건이 오탐(false negative).
   → `norm()` 에서 `<br>` 만 공백으로 치환하도록 수정.
   (`<strong>69%</strong>가` 가 `69% 가` 로 갈라지면 안 되므로 다른 태그는 그대로 제거)
2. **[실제 결함]** 터치 타깃 미달 — 헤더 `.btn--sm` 41px, `.slider__arrow` 40px, `.slider__dot` 24px.
   → 각각 44px 이상으로 확대. 도트는 클릭 영역만 44px, 보이는 막대는 4px 유지.
3. **[측정 방식]** 컬러 비율을 "요소 배경색 × 면적"으로 근사해 퍼플 1% 로 집계됨(무의미).
   → 전체 페이지 스크린샷 PNG 를 직접 디코드(zlib)해 **실제 픽셀**로 측정하도록 교체.

## R4 — 육안 검수 (자동 검사가 못 잡는 것)

자동 100점이어도 눈으로 봐야 하는 것들. 실제로 세 건이 나왔다.

1. **🔴 형광펜 밑줄이 화면에 아예 안 보임.**
   `.hl::before { position:absolute; z-index:-1 }` 로 만들었는데,
   부모 `.hero` 에 배경색이 있어 **가상요소가 부모 배경 뒤로 밀려 사라졌다.**
   자동 검사는 `.hl` 개수만 셌기 때문에 통과했다.
   → 인라인 요소의 `background-image: linear-gradient(...)` 로 교체.
     글자 뒤·부모 배경 앞에 칠해지고, 줄바꿈이 일어나도 각 줄에 따라붙는다.
   → **회귀 검사 추가**: `.hl` 의 배경이 실제로 칠해져 있고 `z-index<0` 가상요소에
     의존하지 않는지 라이브로 확인.
   → `tools/og-image.html` 에도 같은 버그가 있어 함께 수정.

2. **🔴 인용 카드 폭이 256px → 176px 로 눌림.**
   리셋에서 `blockquote` / `figure` 의 브라우저 기본 마진(`1em 40px`)을 지우지 않았다.
   4열 그리드 셀 안에서 좌우 40px씩 먹혀 카드가 쪼그라들고 텍스트가 6줄로 깨졌다.
   → `p, figure, blockquote, dl, dd { margin: 0 }` 로 리셋 보강.
   → 인용 카드를 flex column 으로 바꿔 출처(footer)를 카드 하단에 정렬.

3. **🟡 OG 이미지 헤드라인이 3줄로 깨지고 대시보드 폰이 잘림.**
   → 헤드라인 60px→48px, 좌측 컬럼 560→588px + `white-space: nowrap`,
     폰 목업 위치·크기 조정. 한글 폴백 폰트(전각)에서도 2줄로 유지된다.

## 1차 63점 — 구매자가 페이지를 닫는 이유

1. **"학생 28명 계정을 내가 다 만들어야 하나?"** 실무 부담이 안 보이면 그냥 닫는다.
2. **"안 하고 했다고 하면?"** 숙제 앱의 1번 질문인데 답이 없었다.
   앱에는 이미 서버 검증 기능이 있는데(스크린샷에 문구가 있다) 페이지에 안 팔고 있었다.
3. **"학교 폰 금지인데?"** 웹앱이라 PC로도 되는데 그 말이 어디에도 없었다.
4. 고1이 만들었다는 사실이 원장에겐 지속성 리스크로 읽히는데 방치했다.
5. 문의하면 무슨 일이 일어나는지 몰라 영업 전화 경계심이 생긴다.

## 육안 검수에서 잡은 버그

- **폼 폴백 블록이 제출 전에도 보였다.** `.form__fallback { display: grid }` 가
  `[hidden]` 의 기본 `display:none` 을 이겼다. 감사 반영 때 들어간 이후 계속 노출돼 있었다.
  → `.form__fallback[hidden] { display: none }` 추가.
  → **회귀 검사 추가**: `[hidden]` 인데 높이가 0이 아닌 요소가 있으면 실패.
- 빠른 문구 칩이 34px 이라 터치 타깃 미달 → 44px.
