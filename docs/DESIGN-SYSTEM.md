# 타이거오키드 (TigerOrchid) 디자인 시스템

> **한 문장:** 난초의 보라로 단정하게, 호랑이의 오렌지로 생기 있게.
> 선생님·원장에게는 신뢰(보라·여백·정돈), 아이들 화면이 등장하는 순간에는 에너지(오렌지).

**브랜드 위계:** 페이지의 주인공은 **WORD QUEST**. 타이거오키드는 푸터에 "운영: 타이거오키드"로만 표기.

---

## 1. 컬러

| 역할 | 이름 | HEX | 토큰 | 사용처 |
|---|---|---|---|---|
| 주색 | 오키드 퍼플 | `#7C3AED` | `--c-purple` | CTA 버튼, 링크, 섹션 타이틀 포인트, 아이콘 |
| 진한 주색 | 딥 오키드 | `#5B21B6` | `--c-purple-deep` | 버튼 hover, 강조 텍스트 |
| 배경 틴트 | 라이트 오키드 | `#F3EEFF` | `--c-purple-tint` | 신뢰 섹션·인용 카드 배경, 태그 배경 |
| 액센트 | 타이거 오렌지 | `#F97316` | `--c-orange` | 숫자 하이라이트(69% 등), 공동보스·게임 배지, 형광펜 밑줄 |
| 본문 | 잉크 | `#211A33` | `--c-ink` | 제목·본문 텍스트 |
| 보조 | 그레이 퍼플 | `#6B6480` | `--c-ink-soft` | 서브 카피, 캡션 |
| 배경 | 오프화이트 | `#FCFAFF` | `--c-bg` | 페이지 기본 배경 |
| 카드 | 화이트 | `#FFFFFF` | `--c-surface` | 카드 배경 |
| 라인 | — | `#EAE4F5` | `--c-line` | 구분선·테두리 |
| 오렌지(글자) | — | `#EA580C` | `--c-orange-text` | **글자로 쓰는 오렌지 전용** (아래 참고) |

### 비율 규칙 (엄수)
```
배경·화이트 80% / 퍼플 12% / 오렌지 5% 이하 / 기타 3%
```
오렌지를 남발하면 유치해진다 — **숫자와 게임 요소에만**.

### 접근성 규칙
- 본문은 항상 잉크색(`--c-ink`). 대비 4.5:1 이상.
- 퍼플 버튼 위 텍스트는 **흰색**.
- 오렌지는 **작은 본문 텍스트 색으로 쓰지 않는다** (흰 배경 대비 약 3.0:1 → 미달).
  - 허용: 24px 이상 볼드 숫자 강조, 배지(진한 배경 위 흰 글자), 형광펜 밑줄(배경으로만).

### 오렌지가 둘인 이유

`#F97316` 은 흰 배경 대비 **2.83:1** 이다. 큰 텍스트 기준 3:1 에도 못 미친다.
스펙의 "오렌지는 대비가 부족하니 작은 본문 텍스트에 쓰지 말라"는 지시를 끝까지 지키려면
**칠과 글자를 분리**해야 한다.

| | 색 | 쓰는 곳 |
|---|---|---|
| 칠 | `#F97316` (`--c-orange`) | 형광펜 밑줄, 배지 배경 |
| 글자 | `#EA580C` (`--c-orange-text`) | 숫자 강조 `.stat` (24px+ 볼드) |

- 배지는 **오렌지 배경 + 잉크 글자**(5.94:1). 흰 글자는 2.80:1 로 미달이라 쓰지 않는다.
- 본문 크기(16/17px) 숫자는 오렌지를 아예 쓰지 않는다 — 그 크기에서는 어떤 오렌지도 4.5:1 을 못 만든다.
  히어로의 110명·69% 는 **잉크 볼드**로만 강조한다.

**실측 대비비 (흰 배경 기준)**
| 조합 | 대비 | 판정 |
|---|---|---|
| 잉크 `#211A33` | 15.6:1 | AAA |
| 그레이 퍼플 `#6B6480` | 5.9:1 | AA |
| 퍼플 `#7C3AED` | 5.7:1 | AA |
| 딥 오키드 `#5B21B6` | 8.9:1 | AAA |
| 흰 글자 on 퍼플 | 5.7:1 | AA |
| 오렌지 `#F97316` | 2.83:1 | **글자로 사용 금지** (칠 전용) |
| 오렌지 글자 `#EA580C` | 3.56:1 | 24px+ 볼드 숫자만 (Large Text 3:1 통과) |
| 잉크 on 오렌지 배지 | 5.94:1 | AA |
| 플레이스홀더 `#75708A` | 4.56:1 | AA |

## 2. 타이포그래피

- **헤드라인:** Paperlogy → Gmarket Sans Bold → Pretendard → system-ui
- **본문:** Pretendard (400/600/700만 사용)
- 폴백 스택에 `Apple SD Gothic Neo`, `Malgun Gothic`, `Noto Sans KR` 포함 → CDN 실패 시에도 한글 정상 표시

### 스케일 (데스크톱 / 모바일)
| 용도 | 데스크톱 | 모바일 | 토큰 |
|---|---|---|---|
| 히어로 | 40px | 28px | `--fs-hero` |
| 섹션 타이틀 | 28px | 22px | `--fs-h2` |
| 본문 | 17px | 16px | `--fs-body` |
| 캡션 | 14px | 14px | `--fs-caption` |
| 본문 행간 | 1.65 | 1.65 | `--lh-body` |

### 형광펜 밑줄 (유일한 그래픽 장치)
히어로 헤드라인의 **"먼저 하게"**에만 적용. (2026-08 개편 전에는 "하고 싶어하게")
- 오렌지 40% 불투명도, 텍스트 **뒤쪽 레이어**
- 글자 높이의 약 38%를 아래에서부터 덮음
- 호랑이 줄무늬의 은유 — 페이지에서 이것 하나뿐. 다른 곳에 반복 금지.

## 3. 컴포넌트

### 버튼 — radius 12px
- **Primary:** 오키드 퍼플 배경 + 흰 글자 + 은은한 퍼플 그림자 → hover 시 딥 오키드
- **Secondary:** 잉크 1.5px 외곽선 + 투명 배경
- 최소 터치 타깃 48px

### 카드 (기능 4개) — radius 16px
화이트 배경 / 1px `#EAE4F5` 테두리 / 아주 옅은 그림자 / 퍼플 단색 라인 아이콘

### 인용 카드 (학생들의 말) — radius 16px
라이트 오키드 배경 / 큰따옴표 장식은 **오렌지**

### 숫자 강조 (69%, 110명)
`--c-orange-text` 볼드 + 본문 대비 **정확히 1.5배** (모바일 16→24px / 데스크톱 17→26px).
신뢰 섹션처럼 숫자가 단독으로 놓이는 자리에만 쓴다. 문장 안에 섞인 숫자는 잉크 볼드.

### 섹션 리듬
- 섹션 간 패딩 **96px** (모바일 64px)
- 배경을 **오프화이트 ↔ 화이트로 교차** → 구분선 없이 리듬

### 난초 모티프
문의 섹션 배경에 **한 줄기 난초 라인 드로잉** (퍼플 8% 투명도).
**이거 하나만. 더 넣지 않기.**

## 4. 이미지 규칙

- 스크린샷은 **실제 화면 캡처**를 폰 목업 프레임에 넣고 **2~3도 기울여** 배치, 뒤에 라이트 오키드 블롭
  - 블롭은 폰보다 **커야 한다**(폰 269px < 블롭 340px). 작으면 폰 뒤에 완전히 가려 아무것도 안 보인다.
  - 실제 캡처가 아직 없으면 목업에 **`예시 화면` 배지**(`.phone__tag`)를 반드시 붙인다.
    신뢰로 파는 페이지에서 그려낸 화면을 실제라고 두면 안 된다. 캡처로 교체할 때 배지를 함께 지운다.
- 몬스터/게임 아트는 **3번(해결)·6번(학생들의 말) 섹션에만** — 페이지 상단은 어른의 신뢰 영역
  - **히어로의 데모 자리도 예외가 아니다.** 여기 들어가는 화면은 선생님 대시보드·세팅 화면이어야 한다.
- OG 이미지: 퍼플 배경 + 헤드라인 + 대시보드·게임 화면 나란히 (1200×630)

## 5. 금지 목록

- ❌ 원색 남발, 무지개 그라데이션, 애니메이션 과다 (고객은 교사·원장)
- ❌ 호랑이 무늬 패턴을 배경에 깔기 → 줄무늬는 형광펜 밑줄 하나로만

- ❌ 헤드라인에서 "게임"을 앞세우기 → 스크린샷과 함께일 때만 자연스럽게
- ❌ 난초 라인 드로잉을 문의 섹션 밖에 반복
