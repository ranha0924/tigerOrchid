> 이 문서는 "무엇을, 어떤 순서로, 어떤 기준으로 통과시킬지"를 고정한다.

---

## 0. 목표와 성공 기준

**전환 목표(단 하나):** 방문한 선생님·원장·학부모가 **도입 문의 폼을 제출**하는 것.
학생 가입은 목표가 아니다 → 학생 앱 링크는 푸터에만, 눈에 띄지 않게.

**성공 기준**
1. 스펙의 섹션 1~10 카피가 **문자 그대로** 들어가 있다.
2. "타이거오키드" 디자인 시스템(컬러 비율·타이포 스케일·컴포넌트)을 지킨다.
3. 모바일 우선. 원장·선생님은 폰으로 본다.
4. 스크롤 없이도 문의로 갈 수 있다(상단 고정 CTA).
5. 카톡/기사 공유 시 OG 미리보기가 제대로 뜬다.
6. 정적 페이지 — 빌드 스텝 없이 파일만 올리면 뜬다.

## 1. 기술 선택과 근거

| 결정 | 선택 | 근거 |
|---|---|---|
| 스택 | **순수 HTML/CSS/JS (빌드 없음)** | "학생용 게임 앱과 별개의 정적 페이지". 프레임워크 도입 시 배포·유지비만 늘고 이득 없음. 어디에든(GitHub Pages, Firebase Hosting, Netlify, 기존 도메인 하위 경로) 그대로 올라간다. |
| CSS | CSS 변수 토큰 + 단일 스타일시트 | 디자인 시스템을 토큰으로 고정해야 "오렌지 남발" 같은 이탈을 막을 수 있다. |
| JS | 바닐라, 약 6KB | 슬라이더 + 폼 제출 + 스크롤 정도. 라이브러리 불필요. |
| 폰트 | Paperlogy(헤드라인) / Pretendard(본문), CDN + `font-display:swap` | 스펙 지정. CDN 실패해도 폴백 스택으로 정상 표시되게 설계. |
| 이미지 | SVG(스크린샷 목업·난초·아이콘) + PNG(OG) | 실제 스크린샷 확보 전까지 SVG 플레이스홀더. 벡터라 용량 거의 0. |
| 폼 | **하이브리드**: Google Form(설정 시) → 없으면 mailto 폴백 | 스펙 1안(가장 빠름)을 택하되, 설정 전에도 문의가 유실되지 않게 폴백을 둔다. Firestore(2안)는 백엔드 준비 후 `config.js`만 바꾸면 전환 가능하도록 어댑터 구조. |

```
│   ├── css/style.css        # 레이아웃 · 컴포넌트
│   ├── js/config.js         # 폼 엔드포인트 설정 (여기만 고치면 됨)
│   ├── js/main.js           # 슬라이더 · 폼 · 스크롤
│   └── img/                 # 스크린샷 목업, 난초, OG, 파비콘

    ├── PLAN.md              # (이 문서)

```

## 3. 단계별 구현 계획 + 검증 게이트

각 단계는 **자동 검증 점수 85점 이상**이어야 다음 단계로 넘어간다.
85점 미만이면 수정 후 재검증. 통과 기록은 `docs/VERIFICATION.md`에 남긴다.

### G1 — 기반 (토큰 · 폰트 · 헤드 · 고정 CTA)
- `tokens.css`: 컬러 8종, 타이포 스케일, 간격, radius, 그림자
- `<head>`: title/description/OG/Twitter/canonical/theme-color/JSON-LD
- 상단 고정 헤더 + [도입 문의하기] CTA
- **검증:** 토큰 8색 정의 여부 / OG·Twitter 필수 태그 / 뷰포트 메타 / 대비비 계산

### G2 — 섹션 1~5 (히어로 · 공감 · 해결 · 기능 · 신뢰)
- 히어로 헤드라인 + "하고 싶어하게" 오렌지 형광펜 밑줄
- 데모 영상 자리 → 스크린샷 슬라이드로 대체(유튜브 전환 포인트 주석)
- 스크린샷 3장 폰 목업, 2~3도 기울임, 라이트 오키드 블롭
- 기능 카드 4개 + 퍼플 라인 아이콘
- 신뢰 숫자(69%, 110명) 오렌지 볼드 1.5배
- **검증:** 스펙 카피 문자열 일치 / 헤드라인에 "게임" 미노출 / 숫자 강조 스타일

### G3 — 섹션 6~10 (학생의 말 · 만든 사람 · 요금 · 문의 · 푸터) + privacy.html
- 인용 카드 4개(라이트 오키드 배경 + 오렌지 따옴표)
- 문의 폼 4필드 + 난초 라인 드로잉 배경(퍼플 8%)
- 푸터: 개인정보처리방침 / 이메일 / 인스타 / "운영: 타이거오키드" / 학생 앱(약하게)
- **검증:** 카피 일치 / 폼 필드 4종 + 라벨 연결 / 필수 링크 존재

### G4 — 에셋 (스크린샷 목업 · 난초 · OG · 파비콘)
- 게임/대시보드 화면 SVG 3종 (실제 캡처로 교체 가능한 구조)
- 난초 라인 드로잉 1개 (문의 섹션에만)
- OG 1200×630 PNG (Chromium 렌더)
- **검증:** 파일 존재 / OG 해상도 / 총 용량 예산 / 게임 아트가 3·6번 섹션에만 등장

### G5 — 동작 (슬라이더 · 폼 제출 · 스무스 스크롤 · 접근성)
- 폼 제출: Google Form 설정 시 iframe POST, 미설정 시 mailto 폴백
- `prefers-reduced-motion` 존중, 포커스 링, aria 속성
- **검증:** JS 오류 0 / 폼 검증 동작 / 키보드 접근 / 슬라이더 aria

### G6 — 종합 (반응형 · 성능 · 실렌더 검증)
- 360 / 390 / 768 / 1280 / 1440 뷰포트 스크린샷
- 가로 스크롤 0, 컬러 비율(퍼플 12% / 오렌지 5% 이하) 실측
- **검증:** 전체 항목 종합 점수

### G7 — 독립 에이전트 최종 검증
- 컨텍스트 없는 독립 에이전트가 스펙 원문 대비 감사 → 지적사항 반영 → 재확인

## 5. 하지 말 것 (스펙 명시)

- 원색 남발 / 무지개 그라데이션 / 과한 애니메이션 (고객은 교사·원장)
- 호랑이 무늬 패턴 배경 → 줄무늬는 **형광펜 밑줄 하나**로만 은유
- 스톡 사진 속 외국인 교실 → 실제 화면이 최고의 이미지
- 헤드라인에서 "게임"을 앞세우기 → 스크린샷과 함께일 때만 자연스럽게
- 난초 모티프 남발 → 문의 섹션 **한 줄기 하나만**

## 6. 배포 후 남는 일 (사람이 해야 하는 것)

1. `assets/img/screen-*.svg` → 실제 앱 스크린샷(PNG/WebP)으로 교체
2. `assets/js/config.js`에 Google Form URL + entry ID 입력
3. 1분 데모 영상 완성 → 히어로 슬라이드를 유튜브 unlisted 임베드로 교체
4. 9월 추가 지표(참여율 %, 누적 학습 단어 수, 선생님 코멘트, 언론 보도) → 5번 섹션 주석 슬롯에 삽입
5. 개인정보처리방침 사업자 정보 확정
